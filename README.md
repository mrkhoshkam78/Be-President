# Be President V3.7

## ساختار
```
index.html
styles.css          (fallback)
Css/styles.css
css/styles.css
js/*.js             (اصلی)
*.js                (fallback ریشه)
```

## اجرا
1. کل ZIP را استخراج کنید
2. فایل **index.html** را از **ریشه همین پوشه** باز کنید
3. نباید فقط index را جدا کپی کنید — پوشه‌های js و Css باید کنار آن باشند

## اگر صفحه خالی بود
- Console مرورگر (F12) را باز کنید
- نوار قرمز پایین صفحه پیام خطای لود می‌دهد
